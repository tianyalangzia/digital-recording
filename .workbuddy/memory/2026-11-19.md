## 数据存储改造：从 localStorage 改为本地文件

- **诉求**：用户希望数据自动存成文件，而不是藏在浏览器 localStorage。
- **方案**：Python 本地服务（用户选了 Python 轻量方案，本机 Python 3.13）。
- **架构**：
  - `server.py`：标准库 http.server，提供静态页 + `/api/data` 读写接口，数据存 `data.json`。启动后自动打开浏览器。
  - `index.html`：数据层从 localStorage 改为 fetch 调 `/api/data`，save 用串行队列防乱序。
  - `启动.bat`：双击启动脚本（内容用 ASCII 避免中文编码问题）。
- **验证**：GET/POST 接口读写 data.json 正常，首页 200，前后端语法检查通过。
- **端口**：8765，仅监听 127.0.0.1。data.json 已加入 .gitignore。
