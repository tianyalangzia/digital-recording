# 数码资产记录工具

一个本地运行的数码设备资产管理工具，帮助你登记、查看和统计手头的数码产品（手机、电脑、平板、耳机等），数据自动保存到本地 `data.json` 文件。

## 功能特性

- **资产记录**：添加、编辑、删除、查看设备详情
- **丰富字段**：名称、类型、品牌、型号、购买日期、价格、渠道、序列号、状态、收藏、备注
- **折旧统计**：每台设备的日均成本（¥/天）、使用天数自动计算
- **资产概览**：总资产、总日均、在用数一目了然
- **分类筛选**：按类型胶囊筛选，支持搜索与排序
- **统计报表**：设备总数、累计投入、平均单价、状态分布、分类统计
- **数据落盘**：所有数据自动保存为本地 `data.json` 文件，可手动备份、可进 Git

## 使用方式

需要本机已安装 Python 3。

**方式一（推荐）**：双击 `启动.bat`，服务启动后会自动打开浏览器。

**方式二**：命令行运行

```bash
python server.py
```

然后在浏览器打开 http://127.0.0.1:8765

## 数据存储

- 数据自动保存到项目目录下的 `data.json` 文件
- 手动备份：界面「我的 → 导出备份」可生成独立的 JSON 备份文件
- `data.json` 已在 `.gitignore` 中忽略，不会提交到 GitHub

## 技术说明

- 前端：纯 HTML + CSS + JavaScript 单文件应用
- 后端：Python 标准库 `http.server`，零第三方依赖
- 数据：JSON 文件本地存储
