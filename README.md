# 数码设备台账

一个网页版的个人数码设备记录工具，帮助你集中登记、查看和统计手头的数码产品（手机、电脑、平板、耳机等）。

## 功能特性

- **设备管理**：添加、编辑、删除、查看设备详情
- **丰富字段**：名称、类型、品牌、型号、购买日期、价格、渠道、序列号、状态、保修、备注
- **数量统计**：设备总数、类型数、在用数、已出售数、累计投入金额
- **搜索筛选**：按关键词搜索，按类型 / 状态筛选
- **数据备份**：一键导出 / 导入 JSON 备份文件
- **本地存储**：数据保存在浏览器 localStorage，无需登录、无需联网

## 使用方式

直接用浏览器打开 `index.html` 即可使用，无需任何依赖或构建。

## 技术说明

- 纯 HTML + CSS + JavaScript 单文件应用，零依赖
- 数据持久化于浏览器 localStorage
